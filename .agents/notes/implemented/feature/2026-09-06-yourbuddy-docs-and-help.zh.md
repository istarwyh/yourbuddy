# Agent Note: YourBuddy 文档与应用内帮助

Status: implemented

[English](2026-09-06-yourbuddy-docs-and-help.md) | 中文

## 问题

Y8 需要让新用户直接完成工作，并让专业用户找到扩展办法。已有默认插件、DSH 教程和 Creator 能力提供基础，但分散的入口增加理解成本；产品开发入口先讲桌面源码构建，也容易让插件作者误判准备成本。

## 决策

Y8 通过双语产品指南和应用内 Help 串起默认使用、扩展选择和专业开发。OINK 产品站从现有 DSH 入门教程的正文来源发布内容，并提供写明源码环境前提的简短 Creator 指南。Harbor 是 Y8 维护者深度开发的独立项目，用作深入案例。

自有 Personal Workbench 插件通过公开侧栏底部槽位注册 Help，复用桌面外链请求。菜单支持语言对应的目的地址、键盘导航、折叠布局和打开失败后的地址复制，保留工作台页面，并忽略菜单关闭后到达的旧请求结果。Help 不管理开发进程或项目；用户继续使用 DSH 原生插件和现有开发工具。

## 考虑过的替代方案

**建设插件开发工作台。** 不采用为当前交付。独立实例、项目管理、转换与打包会引入新的产品能力和维护成本，当前缺口首先是理解和寻找既有能力；后续工具需要实际阻碍支持。

**只整理仓库文档。** 不能解决官网与应用内的发现问题，因此正文、站点导航和 Help 同时纳入实施。

## 验证

装配后的无密钥 [Web 路径](../../../../apps/web/tests/yourbuddy-help.e2e.ts)加载构建后的产品插件，验证双语、菜单导航、工作台状态保留、设置帮助及由替代原生桥接返回的打开失败。包测试覆盖目的地址校验和迟到响应。[实施记录](../../../../docs/tech/202609/verification.zh.md)将这些结果与已安装桌面端、真实模型验收分别记录。

## 影响

用户无需先配置模型或创建会话就能找到帮助。开发教程要求准备好的源码 checkout，Creator 指南明确说明这一前提。外部文档依赖网络，不提供离线正文；当前交付不提供小团队协作或自动交付工具。
