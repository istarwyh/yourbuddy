# YourBuddy 使用与扩展引导实施记录

## 已实现范围

[确认的方案](implementation-plan.zh.md)已落实到产品指南、OINK 导航和自有 Personal Workbench 插件。[扩展 Y8](../../user/product/develop.zh.md)说明扩展选择和需求定义，[Creator](../../user/product/creator.zh.md)说明源码使用路径，四篇现有开发教程通过站点发布，保持单一正文。默认插件页说明来源、理由、前提和 Harbor 开发案例。

Help 使用公开侧栏底部槽位，支持语言对应的官方地址、键盘导航和打开失败后选择、复制地址。“我的工作台”卡片链接设置说明。现有 Creator Skill 保留原有指引，已对照新指南核对运行时与持久化说明。本轮未增加开发项目管理器或运行时 API。

## 文档与站点检查

`pnpm run test:docs` 的 15 项检查全部通过；`pnpm run doc-sync` 的 32 项全部通过，包含 SDK 文档构建和站点检查。`pnpm run lint` 完成；站点适配器修改后的完整 lint 发现一个不安全的测试断言，修正后定向重跑通过。`git diff --check` 通过。

`pnpm run website:check` 通过 70 个投影测试、严格 Hugo 构建，并使用 `PRODUCT_SITE_BASE_URL=https://istarwyh.github.io/yourbuddy/` 验证 57 个 HTML 页面。浏览器冒烟检查覆盖双语首页扩展入口、全部五篇开发指南、Markdown 导出、搜索索引和页面错误。嵌套指南保留正文源码链接，并进入顶层栏目全文汇编。开发监听和发布工作流覆盖 `docs/user/`，共享教程的修改也会触发更新。

## 剩余验收与发布

发行维护者负责安装后的 macOS 验收：从真实安装包逐个打开 Help 目的地址，确认操作系统浏览器打开，并返回同一会话。Web 自动化替代了原生 Shell，不能证明这一安装包路径。本次计算机操作连接不可用。

账号持有者仍需执行首次真实模型文件任务，以及 Creator 辅助开发试验，然后停用试验并检查其贡献消失。本次未发送付费模型请求，也未运行 Harbor 评测。Harbor 的操作与版本按随包源码及 README 核对，并非评测实测；Creator 的安装包入口未验证，因此指南明确使用源码 checkout。

本记录覆盖本地验证，不作为安装包发布或官网部署的证据。网站交付需要成功的部署工作流和公开 Help 地址核验；应用发布按[站点同步流程](../../product-website.zh.md#release-synchronization)同步匹配的使用说明。
