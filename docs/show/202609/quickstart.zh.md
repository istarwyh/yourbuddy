# 首次使用：完成一个可检查的任务

[English](quickstart.md) | 中文

本教程的目标是让新用户在一个明确的工作目录中完成一次任务，并找到实际产物。面向 macOS Apple Silicon 的 YourHarness 桌面发行版；发布网页前，需要用对应安装包走完本页步骤并补齐截图。

## 1. 安装并启动

从 [YourHarness Releases](https://github.com/istarwyh/yourharness/releases) 选择标明支持当前系统的安装包，挂载 DMG 并安装应用。下载页同时展示版本、架构、校验和与已知限制；不存在对应产物时，不以源码版本号生成下载承诺。

桌面包携带默认插件、所需的托管运行时和离线依赖资源。普通桌面用户无需先克隆仓库并执行源码构建。启动时等待运行时准备完成；如果失败，应保留启动诊断并查阅故障页。当前 Apple 应用签名与公证仍为暂缓项，发布页需要按真实发行状态解释系统拦截提示；Tauri 更新签名是另一项机制。

## 2. 接入一个可用模型

选择一条适合自己的路径，完成配置后检查当前会话选择的模型：

| 路径 | 操作 | 成功信号与限制 |
|---|---|---|
| 已有 Codex／ChatGPT 使用方式 | 打开设置中的 GPT Auth，检查登录状态，按页面引导登录 | 账号状态可用，模型选择器中有可用 Codex 路由；这是社区插件提供的非官方接入 |
| 使用模型服务的 API | 打开设置 → 模型，添加提供方或保存 DeepSeek 等服务的密钥 | 提供方可选，简单文本请求成功；使用各自服务的凭据与额度 |
| 使用公司网关或自建兼容服务 | 在模型页添加自定义提供方，填写协议、基础地址与模型 | 请求通过实际接口；支持的模态和工具能力需与服务匹配 |

GPT Auth 的前提与限制见[默认插件](plugins.zh.md)；API 与自定义模型的详细配置见[模型配置指南](../../user/guide/providers.zh.md)。不要把完整密钥或登录文件粘贴到对话里，也不要把独立 DSH 环境中已经配置密钥视为 YourHarness 已经完成配置。

## 3. 选择工作目录

在“选择工作区”中添加并选中一个专用于练习的文件夹，再创建会话。工作区决定 Agent 处理文件的位置；未选中工作区时输入框不可用。第一项任务应使用你明确愿意让 Agent 读取和写入的练习目录。

## 4. 创建并检查第一个产物

在会话中发送下方示例。示例属于操作演示，不是性能或质量基准。

> 在当前工作目录创建一份 hello-yourharness.md，包含本周要完成的三件事和每件事的验收条件。完成后告诉我文件位置，并概括你写了什么。

根据界面提示处理需要审批的操作。等待任务结束后，通过 Better Sidebar 打开文件，检查三件事与验收条件是否实际存在。如果工作区是 Git 仓库，可以进一步查看差异；仅收到助手的完成说明不足以判断文件已经写入。

## 5. 熟悉常用入口

| 入口 | 初次体验 |
|---|---|
| Better Sidebar | 查看练习目录、打开刚创建的 Markdown，并观察终端或 Git 面板 |
| 已有会话输入区的 Context Doctor | 展开上下文审计，查看指令、技能和工具的估算占用 |
| 设置 → 通用设置 → 我的工作台 | 修改名称或 Logo、预览并保存，重新打开后检查持久化 |
| 设置 → 插件市场 | 查看一个插件的用途、来源与安装资格，暂时无需安装更多插件 |

## 6. 按需配置网络和更新

网络受限时，打开设置 → 通用设置 → 网络代理，选择直连、跟随系统或自定义固定代理。分别检查桌面草稿链路与正在运行的 Host 链路；保存、重启后再次测试，确认生效。自定义代理要求 HTTP 与 HTTPS 地址，当前不执行 PAC 或保存代理认证信息。企业证书问题按设置卡提供的 PEM 证书入口处理。

通过设置 → 通用设置 → 应用生命周期检查更新或重启。插件市场安装新插件后也使用这里的重启入口，等待新客户端插件被扫描。默认内置插件随 YourHarness 应用发行升级；插件页显示上游新版本，不代表本机已经升级。

## 遇到问题时

| 现象 | 下一步 |
|---|---|
| 输入框不可用 | 先确认选中了工作区 |
| 模型不可用或请求失败 | 核对当前模型、账号／密钥、额度和网络测试；错误不一定来自应用启动 |
| 找不到刚创建的文件 | 检查当前工作目录、工具结果与实际写入路径 |
| 新插件安装完成但没有界面 | 确认安装目标是 YourHarness 的 Web Profile，重启应用并检查插件是否加载 |
| Context Doctor 没有显示 | 先建立已有会话；尚无会话标识的新会话不显示会话级控件 |
| Harbor 没有可诊断的历史 | 先完成该工作目录中的业务会话，或明确提供 Query／Dataset |

## 数据与后续学习

macOS 的应用数据根目录为 `~/Library/Application Support/YourHarness`，其中 `dsh-home` 管理该应用的会话、配置与凭据。用户选择的项目文件仍写入对应工作目录；Codex Auth 会复用原生 Codex 登录存储。排障分享材料应去掉凭据与敏感任务内容。

随后选择一个[典型工作流](workflows.zh.md)。Harbor 等进阶功能的任务环境和费用前提在其流程中介绍，不作为完成首次普通任务的条件。
