## 如何解释当前状态

当前源码的桌面版本为 `0.3.0`，产品运行时面向 macOS Apple Silicon。这个版本号和目录中的描述只证明本次内容核对所针对的源码状态，不证明同版本的 YourHarness 安装包已经发布，也不证明每个插件功能都经过真实账号或 Docker 验收。

对外发布时，下载页、截图与支持范围必须对应一个实际发行版本；用[发布记录与验证归档](../../releases/README.zh.md)连接说明和证据。本文不复用旧品牌的安装包作为新品牌的发布证明。

## 内容范围

产品默认集成的五个外部插件、自有 Personal Workbench，以及仓库内的 Codex Subagent 提供方均有说明。这里的“外部插件”表示它来自独立项目，由 YourHarness 选择并打包；不表示 DeepSeek Harness 官方默认提供，也不表示原作者为 YourHarness 的全部行为背书。

“为什么默认集成”是本次基于插件能力与产品目标整理出的产品理由。具体来源、版本和行为证据放在[默认插件](plugins.zh.md)，不把推导出的理由写成未经核实的作者原话。

## 维护方式

这些文件是按月保存的内容方案。建站时应把采纳的内容放入对应用户文档页面，并维护一个正文来源；安装命令、模型列表、插件版本和发布状态继续引用各自的实现或发行记录。中英文文件成对维护；站点不直接公开内部核对说明和素材待办。
