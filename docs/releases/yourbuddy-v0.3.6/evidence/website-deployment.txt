Failure and recovery
--------------------

The web-access dependency checker found a five-hour-old CDP proxy that no
longer completed its Chrome WebSocket handshake. The exact proxy process was
stopped and recreated without stopping Chrome or YourBuddy. Both the original
and replacement proxy attempts then timed out waiting for host browser
authorization. These attempts are retained as tool limitations and are not
counted as either website success or failure. Deployment metadata, public HTTP,
and static-DOM link inspection provide the passing observations above.
