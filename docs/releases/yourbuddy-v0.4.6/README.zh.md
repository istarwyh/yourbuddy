## 面向用户的发布说明

### 改了什么

YourBuddy 现在内置官方 DSH 0.2.0-rc.1 源码，同时保留 YourBuddy 桌面身份、工作台和产品集成。组件安装可以回收已终止所有者留下的锁，但不会删除活跃所有者的锁。Oil Creator 字幕工具会继承系统与 Homebrew 可执行文件路径。发布工作流也会构建带 YourBuddy 品牌的客户端，并记录准确的 DSH 发布 Commit。

### 解决了什么问题

组件操作意外中断后可能遗留 `component.lock`，阻止后续安装或修复。打包后的字幕工具也可能找不到交互式终端中可用的命令。首次 0.4.5 发布还因为 DSH 源码已变为 0.2.0-rc.1、发布记录仍停留在 0.1.7-rc.2，而在产物构建前停止。

### 在哪里使用

YourBuddy 安装或修复托管运行时组件时使用锁恢复。Oil Creator 启动 Python 字幕流程时使用可执行文件路径修复。同步后的 DSH 核心用于会话、工具、设置和 Web 工作台。

### 如何体验

启动 YourBuddy，继续使用现有工作台。在先前进程中断后重试托管组件操作，可以验证锁恢复。从导出视频启动 Oil Creator 字幕生成，可以验证打包后的命令行工具查找。

### 安装或升级

发布后，从 GitHub Release 安装 Apple Silicon Bootstrap 或 Offline DMG。现有设置、会话、工作区、凭据和组件缓存无需迁移。

### 兼容性、迁移与限制

本版本面向 macOS Apple Silicon，不需要数据迁移。源码测试覆盖锁所有权、发布元数据、TypeScript 集成、文档一致性和桌面运行时构建路径。工作流已发布带签名的更新元数据、校验和、Bootstrap 与 Offline DMG，以及运行时组件归档。安装后启动、打包 WebView 交互、Apple Developer 签名和公证尚未验证。
