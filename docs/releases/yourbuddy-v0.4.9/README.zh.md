## 面向用户的发布说明

### 变更内容

启动页保留下载进度和终态错误，页面重新加载后仍可查看。瞬时下载故障会有界重试，匹配的组件分片可以续传。“重试启动”只重启失败的应用一次；“复制诊断信息”保存显示的详情。

### 解决的问题

中断的下载和安装不再被静默当作完成。当前组件集仅在 Host 完成鉴权就绪后激活。准备、就绪或激活失败时保留原 active 记录，但不会启动旧 Harness。

### 使用位置

在 YourBuddy 下载和准备当前版本时，使用 Bootstrap 启动页。

### 体验步骤

启动 YourBuddy，观察组件、阶段与字节进度。如果启动失败，查看或复制错误，再点击一次“重试启动”。匹配的下载分片可在下一次尝试中续传。

### 安装或升级

发布后，可在 GitHub Releases 选择 Bootstrap 或 Offline DMG。Bootstrap 下载运行时组件；Offline 内置同一组组件归档。应用更新器选择完整的 Offline 应用归档。

### 兼容性、迁移与限制

本版本面向 macOS Apple Silicon。恢复流程只准备当前 manifest 目标，不提供旧版本兼容、降级支持或 Last Known Good 回退。失败时保留原 active 记录不代表会启动旧运行时。尚未验证 Apple Developer 签名和公证。正式包的原生安装、已安装应用自动更新、企业代理断流以及完整工作台尚未验证。
