## 面向用户的发布说明

### 改了什么

YourBuddy 将内置 DSH 核心同步到当前上游版本，同时保留 YourBuddy 桌面身份、内置工作台和产品集成。组件安装现在可以回收已终止所有者留下的锁，但不会删除仍在运行的所有者持有的锁。Oil Creator 字幕工具也会继承桌面应用的可执行文件搜索路径，包括打包应用常用的系统与 Homebrew 位置。

### 解决了什么问题

组件操作意外中断后可能遗留 `component.lock`，阻止后续安装或修复。打包后的字幕工具也可能找不到交互式终端中可用的命令。上游合并还需要明确处理兼容性，才能让 YourBuddy 专属的对话、桌面运行时、发布和文档行为继续保持内部一致。

### 在哪里使用

YourBuddy 安装或修复托管运行时组件时会使用组件锁恢复。Oil Creator 从导出视频启动字幕流程时会使用可执行文件路径修复。同步后的 DSH 核心用于会话、工具、设置和 Web 工作台。

### 如何体验

启动 YourBuddy，继续使用现有工作台。要验证锁恢复，可在先前进程中断后重试托管组件操作。要验证 Oil Creator，可从导出视频启动字幕生成，并确认打包应用能够找到所需命令行工具。

### 安装或升级

发布后，从 GitHub Release 安装 Apple Silicon Bootstrap 或 Offline DMG。现有设置、会话、工作区、凭据和组件缓存无需迁移。

### 兼容性、迁移与限制

本版本面向 macOS Apple Silicon，不需要数据迁移。源码测试覆盖锁所有权、发布元数据、TypeScript 集成、文档一致性和桌面运行时构建路径。正式 DMG 构建、公开校验和、更新元数据、安装后启动、打包 WebView 交互、代码签名和公证，需要等待发布工作流与发布后检查完成。

### 操作步骤

1. 合并当前上游 DSH 分支，在保留 YourBuddy 产品集成的同时解决语义冲突，并恢复 YourBuddy 发布身份。
2. 验证发布版本一致性和桌面组件所有权，然后在打 Tag 前检查 TypeScript 与文档集成。

### 预期结果

候选版本保持统一的 YourBuddy 版本和应用身份，包含同步后的 DSH 核心，只回收遗留组件锁，保持活跃所有者互斥，并且不出现文档或 TypeScript 集成失败。

### 实际结果

七项发布版本测试和六项组件测试通过。组件测试覆盖遗留锁恢复与拒绝第二个活跃操作。仓库类型检查通过，候选版本准备前 `doc-sync` 的全部 43 项门禁通过。随后 Tag 工作流在产物构建前停止，因为 `DSH_UPSTREAM.json` 仍记录 0.1.7-rc.2，而内置源码已经是 0.2.0-rc.1。

### 证据

- 操作前：上游同步替换了桌面发布身份，逐行合并还留下了不兼容的 TypeScript 与 Rust 组合。
- 执行中：合并保留上游历史，同时恢复内部一致的 YourBuddy 对话、桌面运行时、发布和文档集成。
- 结果：0.4.5 版本源一致，聚焦 Rust 与发布测试通过，候选版本可进入发布工作流。
- 失败与恢复：首次 Rust 编译暴露语义合并冲突；恢复内部一致的 YourBuddy 运行时集合后，发布准备前编译错误归零。
