# 通过账号菜单打开设置

[English](guide.md) | 中文

## 变更

加载账号界面的 Web Profile 将侧栏独立设置按钮替换为**账号菜单 → 设置**。这包括基于 Web 的 YourBuddy 工作台。本次变更将账号菜单扩展至 Web 客户端，不改变菜单中的设置动作。未加载账号界面的 Profile 仍保留独立设置按钮作为回退。

## 迁移

1. 打开侧栏的**账号菜单**，再选择**设置**。账号菜单生效时，不要再寻找单独的设置按钮。
2. 确认设置对话框打开，再选择所需分区。当前控件说明见[工作台设置](../../../user/product/settings.zh.md)。
3. 将原先定位侧栏独立设置按钮的浏览器自动化改为先打开账号菜单，再选择其中的设置项。仍须检查真实设置对话框是否出现；仅检测到菜单不代表设置可达。此导航变更不需要修改设置文件。
