# 处理文件与检查成果

[English](workspace.md) | 中文

把对话放在实际工作成果旁边。

## 选择正确目录

开始前添加并选中工作区。Agent 文件操作与 Harbor 工具请求使用当前会话的工作目录。陌生任务先使用练习文件夹，并核对工具返回的实际路径。

## 检查产物

Better Sidebar 提供文件树、编辑器、预览、终端、Git 和后台任务面板。打开生成的 Markdown 或代码，对照需求，检查命令结果。Git 操作与真实终端会影响实际工作区。

## 阅读办公文件

从对话旁的文件树打开 PDF、Word 文档、演示稿或工作簿。这些格式使用右侧 Sidebar 中已有的文档预览，而不是工作台的代码编辑器。会话中的文件链接在 YourBuddy 内打开时也使用同一预览。滚动浏览文档页面或幻灯片，使用浮动缩放控件，选择或复制可用文本。查看表格时，切换工作表标签并滚动单元格区域。阅读结束后关闭预览标签页；再次打开文件会创建新的视图。

| 文件 | 只读预览 | 重要限制 |
|---|---|---|
| `.pdf` | 页面、缩放、文本选择 | 扫描页面需要 OCR 才能选择文字；此处不提供 OCR |
| `.docx`、`.doc` | 本地转换为 PDF 页面 | 字体与排版可能不同于 Word；缺字体提示覆盖 DOCX，不覆盖二进制 DOC |
| `.pptx`、`.ppt` | 本地转换为静态 PDF 页面 | 不播放动画；缺字体提示覆盖 PPTX，不覆盖二进制 PPT |
| `.xlsx` | 工作表、滚动、选择与复制 | 只显示已保存的公式结果；不渲染图表、图片、形状、数据透视表和条件格式 |
| `.xls` | 工作表与已保存的单元格值 | 格式保真度低于 XLSX；不支持字体、边框和冻结窗格 |
| `.csv`、`.tsv` | 可滚动的表格 | 值保持为字面文本，包括看起来像公式的文本 |

工作簿预览不会重算公式。缺少已保存结果的单元格保持空白；提示会指出结果可能不完整或不准确。XLSX 预览还会指出检测到但未显示的绘图和条件格式。将预览用于报告或计算前，请先阅读这些提示。

### 预览不完整时

出现缺字体提示时，查看其详情，并在原应用中核对重要分页或中文文本。遇到不支持、过大或预览失败的文件，使用文档标题栏的**打开**菜单选择已安装的应用，或选择**显示文件位置**。不支持和过大的文件还会在预览区域提供这一恢复入口。大小与转换限制会拒绝预览，而不是静默显示截断文件；具体限制见[预览参考](../../../packages/client/ui-sidebar-documentpreview/README.zh.md)与[转换参考](../../../packages/document/office-to-pdf/README.zh.md)。

### 离线使用与隐私

预览组件属于默认运行时，无需额外安装 Office 预览插件。离线使用前先完成[安装器的组件准备](download.zh.md)：Bootstrap 可能下载缺失的运行时组件，Offline 安装器则随包提供这些组件。打开这些预览不会修改源文件，也不会将文件内容提交给模型或第三方转换服务。PDF 和表格在应用内渲染；Word 和 PowerPoint 在 Host 计算机上转换。另行要求 agent 读取或修改文件时，遵循该任务的模型与工具设置。

此格式矩阵描述预览能力，不保证与 Microsoft Office 排版完全一致。安装包的样例检查、性能测量及尚未验证的范围以各版本的[发布验证记录](../../releases/README.zh.md)为准。

## 委派一个明确任务

默认 Codex 预设可以把自包含任务委派给 Codex Subagent。提供目标、相关文件和完成条件。它共享工作目录，但不会继承完整父会话；登录和权限遵循原生 Codex 配置。加载提供方并不会启动子进程。

## 有依据地管理上下文

Skill 提供可复用的任务指令；插件增加运行时能力或界面。额外指令和工具会占用上下文。精简前使用 [Context Doctor](plugins/context-doctor.zh.md)，修改后再检查一个代表性任务。

可选控件见 [Better Sidebar](plugins/better-sidebar.zh.md)，反复任务的质量检查见[评测](evaluation.zh.md)。
