# YourBuddy

[English](home.md) | 中文

让每个人，都有自己的 AI 工作台。

通用 AI 工具解决共性问题。YourBuddy 把你习惯的模型、Skill、Plugin、文件和专业流程装进同一个桌面工作台，让它按你的工作方式持续生长。

DSH 提供带 WebUI 的 AI 运行时，Y8 提供可直接使用的基础组合。用 Skill 固化可重复的流程与标准，用 Plugin 加入工具、服务和界面，而不必从零组装应用。了解[产品理念](about.zh.md)。

YourBuddy 通过 GitHub Releases 提供 macOS Apple Silicon 安装包。下载页始终指向最新公开版本，并记录平台要求与安装限制，不需要随版本更新官网链接。
