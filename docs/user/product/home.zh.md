# YourBuddy

[English](home.md) | 中文

你的 AI 搭档，就在你的工作区。

读资料、写文件、运行工具。选择你习惯的模型，在自己的 Mac 上完成任务，也能随时查看文件和改动。

DSH 提供带 WebUI 的 AI 运行时，Y8 提供可直接使用的默认组合。专业需求所需的领域分析引擎和操作面板，可以通过插件继续补齐。了解[产品理念](about.zh.md)。

YourBuddy 0.3.3 正在面向 Apple Silicon Mac 准备发布，用于修复安装版应用的启动认证。0.3.2 仍可用于历史测试，但存在已确认的启动缺陷；安装前请检查当前状态。
