# YourBuddy

[English](home.md) | 中文

你的 AI 搭档，就在你的工作区。

读资料、写文件、运行工具。选择你习惯的模型，在自己的 Mac 上完成任务，也能随时查看文件和改动。

DSH 提供带 WebUI 的 AI 运行时，Y8 提供可直接使用的默认组合。专业需求所需的领域分析引擎和操作面板，可以通过插件继续补齐。了解[产品理念](about.zh.md)。

YourBuddy 0.3.7 已面向 Apple Silicon Mac 发布。Better Sidebar 现在是文件、任务、终端、预览与插件页面所在的可伸缩主工作区，DSH 对话仍显示在右侧并可调整宽度。请在下载页查看安装包 Hash、验证证据与剩余限制。
