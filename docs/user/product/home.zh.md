# YourBuddy

[English](home.md) | 中文

你的 AI 搭档，就在你的工作区。

读资料、写文件、运行工具。选择你习惯的模型，在自己的 Mac 上完成任务，也能随时查看文件和改动。

DSH 提供带 WebUI 的 AI 运行时，Y8 提供可直接使用的默认组合。专业需求所需的领域分析引擎和操作面板，可以通过插件继续补齐。了解[产品理念](about.zh.md)。

YourBuddy 0.3.5 已面向 Apple Silicon Mac 发布。桌面设置与外部链接重新到达原生 Handler；存在冲突全局 Skill 时，Codex Preset 委派仍会使用内置可追踪路径。公开文件、更新签名、App 标识与迁移运行时已独立核验；原生启动与安装包 WebView 操作仍未验证。请在下载页查看安装包 Hash 与限制。
