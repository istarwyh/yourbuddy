# Your first task

English | [中文](start.zh.md)

Create a file in a workspace, then inspect the result yourself.

## Before you begin

You need a supported Mac, a usable model account or API credentials, and a practice folder. Check [download availability](download.md) first. The desktop package carries its default plugins and managed runtimes; ordinary users do not need a source build. Docker is only needed by evaluation workflows that require it.

## Connect and choose a workspace

1. Launch YourHarness and wait for runtime preparation.
2. Open Settings and complete one [model setup path](models.md).
3. Add and select a practice directory in the workspace selector. The input becomes available once a workspace is selected.

## Ask for an output

> Create hello-yourharness.md in the current directory with three tasks for this week and an acceptance criterion for each. Tell me where you saved it.

Respond to approvals when the interface requests them. After completion, open the file in Better Sidebar and inspect its contents. In a Git repository, also check the difference. A completion message alone does not establish that a file exists.

## Continue

Keep working in this session, explore the [file and terminal panels](workspace.md), or [personalize the workbench](settings.md). If a step fails, use [troubleshooting](troubleshooting.md) rather than reinstalling all plugins.
