# Oil Creator

[English](oil-creator.md) | 中文

随应用集成的快照版本：`0.1.0`。来源：[oil-oil/dsh-oil-creator](https://github.com/oil-oil/dsh-oil-creator)。

## 解决的问题

视频与图文生产会生成相互关联的脚本、录屏、字幕、封面、发布材料与数据记录。Oil Creator 让每个项目保持为一个普通本地文件夹，而不是把内容藏进私有数据库。

## 使用方式

选择**内容创作** Agent Preset，打开 **Library** Tab，并请 Agent 检查和配置内容工作台。保存前确认建议的内容目录。先创建选题与脚本，再按需绑定录制、字幕、封面、图文或发布工作流。内置发布 Skills 可以为已启用的视频平台和微信公众号草稿箱准备草稿。

## 默认集成的理由

个人 AI 工作台除了代码和文档，也应支持完成视频与图文作品。专用 Preset 提供内容生产 Persona，插件则把文件、阶段状态、工具与人工检查点保留在一起。

## 限制

核心本地片库和脚本工作流无需可选集成即可使用。录制与剪辑仍由人完成。视频发布需要 Ego Lite 和已登录的创作者账号；微信公众号草稿需要 AppID、AppSecret 与 API IP 白名单。字幕、封面、图文、发布与数据功能需要各自文档指定的外部工具或凭据。草稿准备会停在最终发表或群发之前。接受或上传前，应检查路径、生成文案、字幕、标题与平台匹配结果。
