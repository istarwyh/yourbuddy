# 默认插件组合

[English](index.md) | 中文

提供一个经过选择的起点，同时保留各项目的贡献与归属。

| 插件 | 默认集成的理由 |
|---|---|
| [Codex Auth](codex-auth.zh.md) | 将已有账号连接到模型、搜索与图片能力 |
| [Better Sidebar](better-sidebar.zh.md) | 检查文件、命令、差异与后台任务 |
| [Context Doctor](context-doctor.zh.md) | 理解上下文成本、重复内容与被遮蔽技能 |
| [Plugin Marketplace](marketplace.zh.md) | 安装前发现并了解扩展 |
| [Harbor Evolution](harbor-evolution.zh.md) | 用任务证据支持诊断与受控改进 |

这些是 YourHarness 选择的独立外部项目，不属于 DeepSeek Harness 官方默认发行组合。Harbor 有关联维护者，但仍是独立项目。预装不代表已登录、服务可用或全部可选功能已经开启。

## 自有与上游贡献

YourHarness 自有 Personal Workbench 提供[品牌、网络、更新与重启设置](../settings.zh.md)。仓库内 Codex Subagent 提供[明确任务委派](../workspace.zh.md)，与 Codex Auth 的主模型接入不同。Harbor Skill 与 Python Adapter 是配套组成，无需当作额外产品重复安装。

## 更新与权限

内置快照随 YourHarness 发行升级，用户新增包分别维护。市场 Topic 与 Star 不代表安全审查，安装代码拥有 Host 权限。使用前阅读各插件前提与[产品声明](../../../../YOURHARNESS_NOTICES.md)。
