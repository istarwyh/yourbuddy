# Release status

English | [中文](releases.zh.md)

YourBuddy publishes immutable desktop versions through GitHub Releases. GitHub owns the current-version pointer and downloadable assets, so this website does not duplicate a manually maintained version list.

## Current release

Open the [latest YourBuddy Release](https://github.com/istarwyh/yourbuddy/releases/latest) for its version, release notes, macOS Apple Silicon DMG, checksums, signed updater archive, and update manifest.

## Release history and evidence

[All GitHub Releases](https://github.com/istarwyh/yourbuddy/releases) retain downloadable versions. The repository's immutable [release archives](../../releases/README.md) retain version-specific evidence and known limitations. A successful build does not by itself establish native startup, updater installation, Apple Developer signing, or notarization; consult the selected version's record for those results.

Continue to the [download page](download.md) or [first use](start.md).
