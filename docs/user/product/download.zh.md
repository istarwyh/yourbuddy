# 获取 YourBuddy

[English](download.md) | 中文

桌面目标为 macOS Apple Silicon。安装前请确认发行状态。

## YourBuddy 安装包

已核验的发行记录中，首个 YourBuddy 品牌安装包尚未发布。源码版本号不是下载可用性保证。旧 XiaoHui 产物保留其原名称，不作为 YourBuddy 下载展示。

[查看 GitHub Releases](https://github.com/istarwyh/yourbuddy/releases)，或按[源码构建说明](../../../README.zh.md#run-from-source)运行。

## 桌面包包含什么

默认插件、托管的 Node 与 pnpm 资源、Harbor Python 运行时随包提供。模型访问、在线服务网络以及需要容器的评测流程所用 Docker 仍需准备。目前不支持 Windows、Linux 或 Intel Mac 安装包。

## 更新与验证

YourBuddy 正式发行后，版本页会给出精确安装包、SHA-256 校验和、已知限制与验证记录。应用生命周期中的更新使用 Tauri 签名更新器。Apple 应用签名与公证是独立事项，目前仍暂缓。

继续查看[发行状态](releases.zh.md)与[首次使用](start.zh.md)。
