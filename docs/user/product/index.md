# Use YourBuddy

English | [中文](index.zh.md)

Start with a working task. Add specialized capabilities as your needs become clearer.

## Start using

- [Complete your first task](start.md): connect a model, select a folder, and inspect the generated file.
- [Models](models.md): choose an account or API connection.
- [Workspace](workspace.md): work with files, terminals, and changes.
- [Settings](settings.md): customize the workbench and manage network, updates, and restart.

## Available capabilities

- [Default plugins](plugins/index.md): what comes with Y8, why it was chosen, and what needs configuration.
- [Evaluation](evaluation.md): investigate a task and compare controlled changes.
- [Troubleshooting](troubleshooting.md): start with the operation that failed.

## Extend as needed

- [Extend Y8](develop.md): choose between existing plugins, configuration, Skills, and a new plugin.
- [Develop with Creator](creator.md): describe a need and inspect actual extension interfaces before experimenting.
- [Your first plugin](../develop/basic/index.md): load a small plugin from a prepared source checkout.
- [Harbor as an example](plugins/harbor-evolution.md#development-example): see how a specialized extension combines several components.

The sidebar's Help and guides menu links to these guides while you work. See [Why YourBuddy](about.md) for the product philosophy and the [roadmap](roadmap.md) for possible next steps.
