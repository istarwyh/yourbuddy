# YourBuddy

English | [中文](home.zh.md)

Everyone should have an AI workbench of their own.

General AI tools solve common problems. YourBuddy brings your preferred models, Skills, Plugins, files, and professional workflows into one desktop workbench that grows around the way you work.

DSH supplies the AI runtime and Web UI; Y8 supplies a ready-to-use foundation. Use Skills for repeatable workflows and standards, and Plugins for tools, services, and workbench interfaces, without assembling the application from scratch. Read the [product philosophy](about.md).

YourBuddy publishes macOS Apple Silicon installers through GitHub Releases. The download page always points to the newest public version and records the platform requirements and installation limits without a version-specific website update.
