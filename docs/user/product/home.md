# YourBuddy

English | [中文](home.zh.md)

Your AI buddy, right in your workspace.

Read documents, write files, and run tools. Choose your model, work on your own Mac, and inspect the files and changes along the way.

DSH supplies the AI runtime and Web UI; Y8 supplies a ready-to-use default composition. Plugins can add the domain analysis engine and control panel needed for specialized work. Read the [product philosophy](about.md).

YourBuddy 0.3.6 is available for macOS on Apple Silicon. Enterprise proxy and custom-CA settings now use one explicit policy across the desktop and every managed runtime it launches. Public files, the updater signature, App identity, bundled metadata, and relocated runtime are independently verified; native startup, packaged-WebView interaction, and real enterprise traffic remain unverified. Check the download page for the installer hash and limits.
