## 每个版本会说明什么

版本页说明用户可以完成的工作、精确版本和产物、已知限制，以及实际执行的安装或使用验证。失败、跳过与未验证路径保留可见；构建成功本身不等于已经发布。

[GitHub Releases](https://github.com/istarwyh/yourharness/releases)保存下载产物，仓库[发布记录](../../releases/README.zh.md)定义配套证据。旧品牌发行保留为历史记录，不作为新品牌可用性声明。
