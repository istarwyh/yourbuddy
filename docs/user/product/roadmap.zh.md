# 接下来往哪里走

[English](roadmap.md) | 中文

让用户能完成并检查更多实际工作。以下是候选方向，不是交付日期承诺。

| 方向 | 状态 | 怎样算完成 |
|---|---|---|
| 首次使用路径 | 正在推进 | 受支持 Mac 能安装真实发行版、接入模型、生成文件，并找到匹配的排障说明 |
| 解释默认组合 | 正在推进 | 用户能判断插件来源、可选能力、安装失败原因与更新关系 |
| 可重复的改进 | 候选方向 | 一个脱敏真实案例连接历史诊断、人工确认的失败、固定基线与可比回归报告 |
| 更广的平台支持 | 探索中 | 每个对外支持的平台均验证安装、运行时、插件、更新与卸载路径 |
| 更丰富的个性化与团队使用 | 探索中 | 每项能力有明确用户、可重复任务与合理维护成本 |
| 插件开发引导 | 正在推进 | 专业用户可以按明确的环境前提完成小插件，并通过 Help 找到教程 |
| 团队复用案例 | 候选方向 | 非作者按项目说明使用同一版本的插件与验收样例，不依赖作者账号或目录 |

## 已有基础

源码组合已包含模型选择、工作区任务、产物检查、上下文审计与受控 Harbor 评测。公开可用性仍以[发行记录](releases.zh.md)为准。

## 尚未承诺的事项

Windows、Linux、移动端、云同步、团队权限、完整主题与无人值守自动部署均未承诺交付日期。Apple 签名和公证需要独立的发行工作，图片工作区导出也依赖支持权限策略的二进制写入能力。

欢迎[反馈具体任务或阻碍](https://github.com/istarwyh/yourbuddy/issues)，帮助确定优先级。完成项会链接到对应发行与可验证的用户成果。

后续开发工具投入以实际阻碍为依据：先补说明和案例，再判断是否需要工具。独立开发实例、项目管理器和自动转包不作为默认承诺；当前路径见[扩展 Y8](develop.zh.md)。
