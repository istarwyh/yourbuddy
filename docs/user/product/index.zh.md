# 使用 YourBuddy

[English](index.md) | 中文

先完成一个实际任务，再根据逐渐清楚的需求增加专业能力。

## 开始使用

- [完成第一个任务](start.zh.md)：接入模型、选择文件夹、检查生成的文件。
- [模型配置](models.zh.md)：选择账号或 API 接入方式。
- [工作区](workspace.zh.md)：使用文件、终端和改动检查。
- [工作台设置](settings.zh.md)：个性化界面，管理网络、更新与重启。

## 已有能力

- [默认插件](plugins/index.zh.md)：Y8 带了什么、为什么选择它、还需要什么配置。
- [评测与改进](evaluation.zh.md)：调查任务问题并比较受控修改。
- [故障排查](troubleshooting.zh.md)：从失败的具体操作开始处理。

## 按需扩展

- [扩展 Y8](develop.zh.md)：判断现有插件、配置、Skill 或新插件哪种方式合适。
- [借助 Creator 开发](creator.zh.md)：描述需求，先查询实际扩展接口再试验。
- [第一个插件](../develop/basic/index.zh.md)：从准备好的源码环境加载一个小插件。
- [Harbor 开发案例](plugins/harbor-evolution.zh.md#development-example)：了解专业扩展如何组合多个组件。

工作时可以通过侧栏的“帮助与指南”打开这些说明。产品理念见[为什么做 YourBuddy](about.zh.md)，后续方向见[路线图](roadmap.zh.md)。
