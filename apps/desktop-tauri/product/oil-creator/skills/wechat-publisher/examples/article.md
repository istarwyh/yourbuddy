# 5 个让公众号运营效率翻倍的小技巧

还在手动排版公众号文章？这篇示例演示了 wechat-publisher 支持的所有 Markdown 元素，转换后即为带内联样式的公众号 HTML。

## 一、用 Markdown 写作

把精力放在内容上，排版交给工具。**加粗的重点**会自动使用主题强调色，*斜体*、[链接](https://example.com)、`行内代码` 也都支持。

> 引用块适合放数据来源、金句或补充说明。

## 二、结构化你的内容

无序列表：

- 每 3-4 段配一张图，阅读体验更好
- 小标题控制在 10 字以内
- 文末记得加互动引导

有序步骤：

1. 撰写 Markdown 草稿
2. `convert` 预览排版效果
3. `publish-file` 一键推送到草稿箱

## 三、表格也能用

| 元素 | 支持 | 备注 |
|------|------|------|
| 标题 / 列表 / 引用 | ✅ | 自动套用主题样式 |
| 代码块 | ✅ | 等宽字体 + 浅灰底 |
| 本地图片 | ✅ | 自动上传微信 CDN |

---

分隔线会渲染成居中的装饰符号。试试运行：

```bash
node wechat-publisher.mjs convert examples/article.md --style business
```
