# YourBuddy 0.3.12

## English

YourBuddy 0.3.12 repairs Harbor Historical Session evaluation in the default Host execution mode.

- Harbor Evolution is updated to 0.9.8 as a matched Plugin and Python Adapter pair.
- Host command translation preserves paths already resolved into a Trial directory instead of adding the Trial root twice.
- Historical Session Observation can read its frozen input, verify its Digest, and write the Trial Artifact.
- Failed Jobs remain immutable evidence. Start a new Historical Job after upgrading; the release does not weaken Adapter, Renderer, Judge, Artifact, or Criterion requirements.
- The release retains DSH 0.1.5-rc.2, Oil Creator, the **内容创作** Agent Preset, existing data, and all other product integrations from 0.3.11.

Install the Apple Silicon DMG from this release, or use **Settings → General → Application lifecycle → Check for updates** from an earlier YourBuddy installation. Existing YourBuddy data is retained and no migration is required. macOS 11 or later on Apple Silicon is supported. The application is not yet signed or notarized with an Apple Developer identity; first launch may require the documented macOS override.

## 中文

YourBuddy 0.3.12 修复默认 Host 执行模式中的 Harbor Historical Session 评测。

- Harbor Evolution 升级为 0.9.8，并保持 Plugin 与 Python Adapter 配对一致。
- Host 命令转换会保留已经解析到 Trial 目录的路径，不会重复添加 Trial Root。
- Historical Session Observation 可以读取冻结输入、校验 Digest 并写入 Trial Artifact。
- 失败的 Job 继续作为不可变证据。升级后请启动新的 Historical Job；本版本不会削弱 Adapter、Renderer、Judge、Artifact 或 Criterion 要求。
- 本版本保留 DSH 0.1.5-rc.2、Oil Creator、**内容创作** Agent Preset、现有数据与 0.3.11 的其他产品集成。

请从本 Release 安装 Apple Silicon DMG，或在旧版 YourBuddy 中使用**设置 → 通用设置 → 应用生命周期 → 检查更新**。现有 YourBuddy 数据会保留，无需迁移。支持 Apple Silicon 上的 macOS 11 及以上版本。当前应用尚未使用 Apple Developer 身份完成代码签名与公证，首次启动可能需要按文档执行 macOS 放行操作。
