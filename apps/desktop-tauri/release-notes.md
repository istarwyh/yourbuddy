# YourBuddy 0.4.3

YourBuddy 0.4.3 adds a product-focused splash, same-version Capability Packs for Package + CLI + Skill + UI, and one stable trusted gateway for first-party desktop operations. Harbor advances to 0.10.3 with direct runtime install-and-retry, while the packaged Better Sidebar `clsx` regression guard remains in place. The Bootstrap DMG is accepted only when it is at most 30,000,000 bytes.

YourBuddy 0.4.3 新增聚焦产品定位的启动页、统一 Package + CLI + Skill + UI 版本的 Capability Pack，以及第一方桌面操作使用的单一稳定可信 Gateway。Harbor 升级到 0.10.3，并支持直接安装运行时后重试；打包版 Better Sidebar 的 `clsx` 回归门禁继续保留。Bootstrap DMG 只有在不超过 30,000,000 Byte 时才通过验收。
