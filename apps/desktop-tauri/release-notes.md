# YourBuddy 0.3.22

## English

YourBuddy 0.3.22 carries forward the repaired macOS Agent Browser with additional package and release validation.

- The public package path has been independently verified with a fresh browser profile and real headed Chrome navigation.
- Product-plugin refresh checks now compare DSH prerelease versions correctly and accept current Harbor and Oil Creator dry-run candidates.
- The macOS publication workflow now uses Node.js 24-compatible cache, uv, and pnpm setup Actions.

Install the Apple Silicon DMG from this release, or use **Settings → General → Application lifecycle → Check for updates**. Existing data requires no migration. Completely quit and reopen an older running application after updating. A compatible local Chromium-family browser is required; Xvfb and a separate Ego Lite installation are not required. The application is not signed or notarized with an Apple Developer identity.

## 中文

YourBuddy 0.3.22 延续已修复的 macOS Agent Browser，并补充 Package 与发布验证。

- 公开 Package 路径已通过全新浏览器 Profile 与真实有界面 Chrome 导航的独立验证。
- 产品插件刷新检查现在可以正确比较 DSH 预发布版本，并接受当前 Harbor 与 Oil Creator Dry-run 候选。

请从本 Release 安装 Apple Silicon DMG，或使用**设置 → 通用设置 → 应用生命周期 → 检查更新**。现有数据无需迁移。更新后请完全退出并重新打开旧进程。本机需要兼容的 Chromium 系浏览器，不需要 Xvfb 或单独安装 Ego Lite。应用尚未使用 Apple Developer 身份签名或公证。
