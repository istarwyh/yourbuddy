# YourBuddy 0.3.19

## English

YourBuddy 0.3.19 includes Ego Browser as a reviewed offline default.

- Browser tools and the live Agent Browser tab are available without a separate GitHub or npm plugin installation.
- The pinned `dsh-ego-browser` 0.8.5 snapshot uses YourBuddy's frozen offline dependency closure and yields to an active user-installed bundle.
- Oil Creator workbench actions retain reliable visible feedback when their state changes.

Install the Apple Silicon DMG from this release, or use **Settings → General → Application lifecycle → Check for updates** from an earlier YourBuddy installation. Existing data requires no migration. A compatible local Chrome, Chromium, Brave, or Edge browser is required. The application is not signed or notarized with an Apple Developer identity.

## 中文

YourBuddy 0.3.19 将 Ego Browser 作为经过检查的离线默认插件。

- 无需另外通过 GitHub 或 npm 安装插件，即可使用浏览器工具和实时 Agent Browser 标签页。
- 固定的 `dsh-ego-browser` 0.8.5 快照使用 YourBuddy 冻结的离线依赖闭包；用户自行安装并启用的 Bundle 仍然优先。
- Oil Creator 工作台操作在状态变化时会保留可靠的可见反馈。

请从本 Release 安装 Apple Silicon DMG，或在旧版 YourBuddy 中使用**设置 → 通用设置 → 应用生命周期 → 检查更新**。现有数据无需迁移。本机需要安装兼容的 Chrome、Chromium、Brave 或 Edge。应用尚未使用 Apple Developer 身份签名或公证。
