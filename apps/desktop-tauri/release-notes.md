# YourBuddy 0.4.8

Agent Browser keeps its layout when other plugins reload, and idle preview cleanup no longer starts a capture worker. Oil Creator now shows its Library below Workspaces and Sessions in the left sidebar; selecting an item opens its detail in the middle workbench while keeping the conversation available. Local HTTP media playback and host-path access in Better Sidebar are restored.

修复其他插件重新加载后 Agent Browser 样式丢失的问题，并避免空闲预览清理时启动捕获 Worker。Oil Creator 片库现在显示在左侧 Workspace 与 Session 列表下方；选择内容后，中间工作台显示详情，对话区域仍可使用。恢复本地 HTTP 媒体播放和 Better Sidebar 的宿主路径访问。
