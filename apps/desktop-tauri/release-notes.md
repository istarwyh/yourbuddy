# YourBuddy 0.3.11

## English

YourBuddy 0.3.11 adds a local content-production workbench and a dedicated **内容创作** Agent Preset.

- Oil Creator organizes each video or article as an ordinary local project folder containing scripts, recordings, subtitles, covers, articles, and publication material.
- The new **内容创作** Preset keeps the complete Standard toolset and native Codex delegation while guiding planning, production, packaging, and human review.
- The left Sidebar adds a **Library** view for content projects while preserving the YourBuddy name, Logo, and desktop window controls.
- Core project-library and script workflows work locally. Optional recording, subtitle, cover, article, publishing, and metrics integrations remain separately configured.
- The release uses the latest eligible DSH release, `0.1.5-rc.2`, and freezes the reviewed Oil Creator source, compatibility patch, dependency graph, and offline Store.

Install the Apple Silicon DMG from this release, or use **Settings → General → Application lifecycle → Check for updates** from an earlier YourBuddy installation. Existing YourBuddy data is retained and no migration is required. macOS 11 or later on Apple Silicon is supported. The application is not yet signed or notarized with an Apple Developer identity; first launch may require the documented macOS override.

## 中文

YourBuddy 0.3.11 新增本地内容生产工作台与专用的**内容创作** Agent Preset。

- Oil Creator 把每个视频或图文项目组织为普通本地文件夹，其中可以保存脚本、录屏、字幕、封面、文章与发布材料。
- 新增的**内容创作** Preset 保留完整 Standard 工具集与原生 Codex 委派，并引导选题、生产、打包与人工检查。
- 左侧 Sidebar 新增内容项目 **Library** 视图，同时保留 YourBuddy 名称、Logo 与桌面窗口控件。
- 核心片库与脚本工作流可以在本地使用；录制、字幕、封面、图文、发布与数据功能仍按需单独配置。
- 本版本使用最新可用的 DSH Release `0.1.5-rc.2`，并冻结经过检查的 Oil Creator 源码、兼容补丁、依赖图与离线 Store。

请从本 Release 安装 Apple Silicon DMG，或在旧版 YourBuddy 中使用**设置 → 通用设置 → 应用生命周期 → 检查更新**。现有 YourBuddy 数据会保留，无需迁移。支持 Apple Silicon 上的 macOS 11 及以上版本。当前应用尚未使用 Apple Developer 身份完成代码签名与公证，首次启动可能需要按文档执行 macOS 放行操作。
