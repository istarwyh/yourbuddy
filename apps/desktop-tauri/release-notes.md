# YourBuddy 0.4.7

Automatic updates now install the complete Offline application archive. Harness, Node, pnpm Store, and Harbor seeds are available before restart, so a completed update does not require another download during later startup. Automatic update downloads are larger as a result.

自动更新现在会安装完整的 Offline 应用 Archive。Harness、Node、pnpm Store 和 Harbor Seed 会在重启前进入应用，因此完成更新后，后续启动不再依赖额外下载。相应地，自动更新下载体积会增加。
