# YourBuddy 0.3.23

## English

YourBuddy 0.3.23 adds terminal tabs to the Better Sidebar workbench.

- Choose **New terminal** from the Better Sidebar workbench to open a shell beside the current conversation.
- Terminal tabs keep their PTY process while you switch among cached Sessions and release it when closed.
- The existing native right Sidebar terminal remains unchanged, and xterm stays outside the startup bundle until needed.

Install the Apple Silicon DMG from this release, or use **Settings → General → Application lifecycle → Check for updates**. Existing data requires no migration. Completely quit and reopen an older running application after updating. The application is not signed or notarized with an Apple Developer identity.

## 中文

YourBuddy 0.3.23 为 Better Sidebar 工作台增加终端标签。

- 在 Better Sidebar 工作台选择**新建终端**，即可在当前对话旁打开 Shell。
- 在缓存 Session 之间切换时，终端标签会保留 PTY 进程；关闭标签后会释放进程。
- 现有原生右侧边栏终端保持不变，xterm 仍只在需要时加载，不进入启动 Bundle。

请从本 Release 安装 Apple Silicon DMG，或使用**设置 → 通用设置 → 应用生命周期 → 检查更新**。现有数据无需迁移。更新后请完全退出并重新打开旧进程。应用尚未使用 Apple Developer 身份签名或公证。
