# YourBuddy 0.4.18

**Media Desk** and **Context Insights** are included in the workbench sidebar. Open Media Desk to organize ideas and publishing dates, or Context Insights to see context usage across sessions.

工作台侧栏内置**自媒体工作台**和**上下文洞察**。打开自媒体工作台整理灵感与发布排期，或通过上下文洞察查看跨会话的上下文用量。

YourBuddy adds a terminal installer and an Agent-assisted upgrade path for the application that owns your conversation. This release also updates DeepSeek Harness to 0.2.0-rc.2 and Codex Auth to 0.3.3-rc.4, and fixes plan preview navigation. [Install and upgrade guide](https://github.com/istarwyh/yourbuddy/blob/yourbuddy-v0.4.18/docs/user/product/installer.md).

YourBuddy 提供终端安装程序，也可由 Agent 升级当前会话所属的应用。本版将 DeepSeek Harness 更新到 0.2.0-rc.2，将 Codex Auth 更新到 0.3.3-rc.4，并修复计划预览导航。[安装与升级指南](https://github.com/istarwyh/yourbuddy/blob/yourbuddy-v0.4.18/docs/user/product/installer.zh.md)。

Choose the Bootstrap or Offline DMG for Apple Silicon Macs. Use **Settings → General → Application lifecycle → Check for updates** to update an existing installation.

Apple Silicon Mac 可选择 Bootstrap 或 Offline DMG。已有安装可在**设置 → 通用设置 → 应用生命周期 → 检查更新**中更新。

[Verification archive / 验证归档](https://github.com/istarwyh/yourbuddy/tree/yourbuddy-v0.4.18/docs/releases/yourbuddy-v0.4.18)
