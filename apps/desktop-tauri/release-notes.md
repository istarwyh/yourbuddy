# YourBuddy 0.4.6

YourBuddy 0.4.6 synchronizes the bundled DSH core with the official 0.2.0-rc.1 release while retaining the YourBuddy desktop identity and product integrations. It recovers stale component-install locks after an interrupted process, keeps live component operations mutually exclusive, and lets Oil Creator subtitle helpers find system and Homebrew executables from the desktop environment. This version also corrects the DSH source record and restores YourBuddy-branded client construction in the release workflow.

YourBuddy 0.4.6 将内置 DSH 核心同步到官方 0.2.0-rc.1，同时保留 YourBuddy 桌面身份和产品集成。组件安装进程意外结束后，应用可以回收遗留锁；仍在运行的组件操作继续保持互斥；Oil Creator 字幕工具也能找到系统与 Homebrew 可执行文件。本版本还修正 DSH 源码记录，并恢复发布工作流中的 YourBuddy 品牌客户端构建。
