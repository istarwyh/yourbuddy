# YourBuddy 0.4.12

Network proxy preflight and the active Host now share the same policy. Bundled plugins match Harness 0.2, and pinned Ego Browser refresh preserves its runtime record. Every desktop release retains prepared browser and native Offline acceptance.

网络代理预检查与生效的 Host 共用同一策略。内置插件与 Harness 0.2 对齐，固定的 Ego Browser 刷新保留 Runtime 记录。每次桌面发布均保留浏览器与原生 Offline 验收。

macOS Apple Silicon only. Installed proxy save/restart, real providers, upgrade/downgrade and Apple notarization remain unverified unless separately recorded. Historical Oil timing/order failures remain documented; the current full product-refresh aggregate passed.

仅支持 macOS Apple Silicon。已安装应用的代理保存/重启、真实 Provider、升级/降级与 Apple 公证须以单独记录为准。保留历史 Oil 时间/顺序失败记录；本次完整 product-refresh 聚合通过。
